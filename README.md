# Sweep Calculator

Early standalone dashboard prototype. Static HTML/CSS/JavaScript, no dependencies.

## Features
- Player Wallet and New Load entries
- Backend reload transactions and balance reconciliation
- Provider fee calculation (percentage + fixed fee per transaction)
- Settings for games, rates, providers and closing time
- Local browser autosave and JSON export

## Important
This is a **local-only prototype**. It does not yet implement secure authentication, worker roles, Supabase cloud synchronization, transaction editing/approvals, or production accounting reports. Do not use it for sensitive or operational financial data until those features are implemented and tested.

Deploy with Vercel Framework Preset: Other; no build command; output root.
